SLIDE 2 (what is Java, about 80 seconds)
Java is a programming language used for web applications, Android apps, enterprise systems, and big data tools. Its main promise is "write once, run anywhere." You write your code once, and it runs on Windows, Mac, and Linux, because Java code runs on the Java Virtual Machine.
Look at the diagram. Your code is saved as a .java file. The compiler, called javac, turns it into bytecode. Then the JVM, the Java Virtual Machine, runs that bytecode on your computer.

SLIDE 3 (install the JDK, about 150 seconds)
The JDK is the Java Development Kit. It contains the compiler, javac, and the tools you need. We will use JDK 21, which is a Long Term Support release, so it will be supported for years.
Go to adoptium.net and download the Temurin JDK 21 installer for your operating system. Run the installer and keep the default options. On Windows, tick "Set JAVA_HOME" and "Add to PATH".
Now open a terminal and type java dash version, then javac dash version. You should see a version number starting with 21. If you do, the JDK is installed correctly.

SLIDE 4 (install IntelliJ, about 120 seconds)
An IDE is an editor with extra help. It highlights errors, completes code, and runs your programs with one click. We will use IntelliJ IDEA Community Edition, which is free.
Download IntelliJ IDEA Community Edition from the JetBrains website and install it. Open it, choose New Project, select Java, pick JDK 21, and name the project VortexJava.

SLIDE 5 (first check, about 100 seconds)
Let's confirm everything works. Create a class named Main. Inside it, print a message. We will write the full Hello World program in lesson two. For now, just check that you can run a program and see the output.
Press the green run button. If you see "Java is ready!" in the console, your setup is complete.
